**풀 전에 전투를 파악하고, 전투 중에는 살아남으세요.**

Bosses는 보스 전투가 어떻게 흘러가는지 — 몇 줄의 간결한 문장으로, 적절한 순간에, 적절한 채널로 알려줍니다. 보스를 대상으로 지정하면(또는 애드온이 전투 시작을 알아서 감지하면) 전술의 핵심을 얻습니다: 탱커가 무엇을 주시해야 하는지, 누가 무엇을 회피해야 하는지, 무엇을 끊어야 하는지, 절대 서 있으면 안 되는 곳은 어디인지. 애드온이 기본 바탕을 준비해 둡니다: 모든 레이드, 던전, 월드 보스마다 구조와 기본 제안이 들어 있어 아무것도 쓰지 않고 바로 쓸 수 있습니다. 진짜 재미는 그 위에서 시작합니다: 각 플레이어(길드)가 올리는 수정과 설명이 그 바탕을 여러분 길드만의 전술로 바꿔 줍니다.

## 주요 기능

- **대상 NPC를 설명**합니다 — 명령 한 줄, 또는 전투 시작 때 완전 자동 (타이머 없음, 전투 자동화 없음; 자동 모드는 끌 수 있습니다)
- **바로 쓸 수 있고 언제든 고칠 수 있는 제안**과 검증된 주문 링크: 각 줄이 실제 기술 이름을 부르며, 채팅에 클릭 한 번으로 들어갑니다
- **자체 경고 프레임**: 전투 중에는 게임이 애드온 채팅을 막기 때문에 전체 설명이 화면에 뜹니다 — 드래그, 닫기(X / ESC) 가능하고 전투 후 15초 뒤 자동으로 숨으며, 논전 상태에서는 **«채팅으로»** 버튼으로 파티와 공유합니다
- **읽는 사람의 언어로 표시되는 주문 이름**, 게임 데이터베이스에서 실시간 조회 (마우스를 올리면 툴팁이 보입니다)
- **스마트 채널 선택**: 레이드 / 파티 / LFG 인스턴스 채팅 자동 — 또는 길드 / 로컬 / 프레임 전용으로 고정
- **미니맵 버튼**: 인스턴스 안에서는 그 구역의 모든 보스 드롭다운을 열고, 밖에서는 대상을 설명합니다
- **내 메모가 데이터베이스보다 우선**: `/bosses + 텍스트`로 어떤 NPC에든 내 문장을 추가 — 모든 언어, 캐릭터별 저장
- **설명을 게임 안에서 편집**: 경고 프레임의 **편집** 버튼(또는 `/bosses EDITAR [id]`)이 메모 편집기를 열어줍니다 — 주문 링크와 줄 추가, 순서 변경, 삭제, 프레임 미리보기
- 설정 패널은 **설정 → AddOns → Bosses** — 변경 사항이 즉시 적용되며 외부 라이브러리가 없습니다
- 선택 사항인 **디버그 모드**가 `WTF` 폴더에 감지 로그를 기록해, 말없이 지나가는 보스를 보고하기 쉽게 만듭니다

## 명령어

```text
/bosses               대상 NPC를 설명합니다
/bosses <id>          해당 id의 NPC를 설명합니다
/bosses + 텍스트      대상 NPC에 내 문장을 추가합니다
/bosses !             대상 NPC의 설명을 제거합니다
/bosses CANAL auto    레이드 / 파티 / LFG 출력 (기본값)
/bosses CANAL guild   길드 채널 출력
/bosses CANAL local   내 채팅 프레임에만 출력
/bosses CANAL frame   경고 프레임에만 출력 (개인 브리핑)
/bosses IDIOMA auto|es|en|fr|de|ru|pt|zh|ko   설명 언어 (auto = 게임 클라이언트 따름)
/bosses DEBUG on|off  WTF에 감지 로그 기록; /bosses log 표시
/bosses EDITAR [id]   설명 편집기를 엽니다 (내 메모를 위한 실제 UI)
/bosses ?             전체 도움말
```

**지금 해보기:** `/bosses 23576` — Nalorakk, Zul'Aman.

## 알아둘 것

- 2011년 *Boses*로 태어난 가족의 베테랑: **Nas**(자동 인사)와 **MarcoPolo**(상인 자동화)도 함께
- **retail (Midnight 12.1)**과 **Classic**에서 동작: MoP Classic, TBC Classic, Classic Era
- 저장소에는 데이터 팩을 손보는 로컬 **웹 에디터**도 있습니다 (개발자 도구, 로컬 실행: `npm start`)
- Modern 애드온 정책과 완전히 일치: 정보는 당신의 통제 하에, 전투 자동화는 결코 없음
- **옛 Boses 애드온에서 업그레이드?** `WTF\Account\<계정>\SavedVariables\Boses.lua` → `Bosses.lua`(캐릭터별 사본 포함)로 복사하고 다시 불러오면 메모, 설정, 디버그 로그가 자동으로 넘어옵니다
