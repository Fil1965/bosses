**Узнай бой ещё до пулла — и переживи его.**

Bosses объясняет, как устроен бой с боссом — в нескольких чётких строках, в нужный момент, на нужном канале. Выберите босса (или позвольте аддону самому заметить начало боя) и получите суть тактики: за чем следить танку, кого куда уворачиваться, что перебивать и в чём нельзя стоять. Аддон готовит для вас основу: структура и базовые подсказки для каждого рейда, подземелья и мирового босса — можно пользоваться сразу, не написав ни строчки. Настоящая ценность приходит сверху: правки и объяснения, которые добавляет каждый игрок — или целая гильдия, — превращают эту основу в тактику вашей группы.

## Что умеет

- **Объясняет выбранного NPC** несколькими телеграфными строками — одна команда или полностью автоматически при начале каждого боя (без таймеров и автоматики боя; авто-режим можно выключить)
- **Готовые подсказки, которые можно править**, с проверенными ссылками на заклинания: каждая строка называет реальную способность — одним кликом в ваш чат
- **Своё окно оповещений**: во время боя игра блокирует чат аддонов, поэтому полное объяснение показывается на экране — перетаскивается, закрывается (X / ESC), **меняет размер**, сворачивается в одну заголовковую панель, позицию можно зафиксировать, есть кнопки «предыдущий / следующий», чтобы вернуться к уже показанным объяснениям, а также настраиваются прозрачность, максимальная высота и размер шрифта (раздел «Окно оповещений» в панели, с опцией оставить окно видимым всегда вместо автоскрытия через 15 с); вне боя кнопка **«В чат»** делится им с группой, а в режиме «только окно» кнопка **«В группу»** отправляет его в ваш рейд- / инстанс- / групповой / say-чат
- **Названия заклинаний на языке читателя**, берутся в реальном времени из базы игры (наведите курсор — увидите подсказку)
- **Умный выбор канала**: рейд / группа / чат инстанса LFG автоматически — или вручную гильдия / локально / только окно
- **Кнопка у мини-карты**: внутри инстанса открывает список всех боссов зоны; снаружи — объясняет вашу цель
- **Ваши заметки важнее базы**: `/bosses + текст` добавляет вашу строку к любому NPC, на любом языке, для каждого персонажа
- **Редактируйте любое объяснение прямо в игре**: кнопка **изменить** в окне (или `/bosses EDITAR [id]`) открывает редактор заметки — добавляйте ссылки на заклинания и строки, меняйте порядок, удаляйте и смотрите предпросмотр; NPC без записи тоже появляется в окне, и его описание можно написать с нуля
- Панель настроек в **Настройки → AddOns → Bosses** — изменения применяются сразу, без внешних библиотек
- Необязательный **режим отладки** пишет журнал обнаружения в папку `WTF` — молчаливого босса легко отчитать

## Команды

```text
/bosses               объясняет выбранного NPC
/bosses <id>          объясняет NPC по его id
/bosses + текст       добавляет вашу строку к выбранному NPC
/bosses !             удаляет объяснение выбранного NPC
/bosses CANAL auto    рейд / группа / чат LFG (по умолчанию)
/bosses CANAL guild   вывод в канал гильдии
/bosses CANAL local   только ваш фрейм чата
/bosses CANAL frame   только окно оповещений (личные брифинги)
/bosses IDIOMA auto|es|en|fr|de|ru|pt|zh|ko   язык объяснений (auto = как в игре)
/bosses DEBUG on|off  журнал обнаружения в WTF; /bosses log показывает его
/bosses EDITAR [id]   открывает редактор объяснений (настоящий UI для ваших заметок)
/bosses ?             полная помощь
```

**Попробуйте сейчас:** `/bosses 23576` — Nalorakk, Zul'Aman.

## Хорошо знать

- Родился как *Boses* в 2011; ветеран семьи: попробуйте также **[Nas](https://www.curseforge.com/wow/addons/nas)** (автоматические приветствия) и **[MarcoPolo](https://www.curseforge.com/wow/addons/marcopolo)** (автоматизация торговцев)
- Работает на **retail (Midnight 12.1)** и **Classic**: MoP Classic, TBC Classic, Classic Era и **WoW Forever (1.60.1, Classic+)**
- В репозитории живёт и локальный **веб-редактор** для доводки паков (инструмент разработчика, запуск локально: `npm start`)
- Полностью в духе политики аддонов Modern: информация под вашим контролем, никакой автоматики боя
- **Миграция со старого аддона Boses?** Скопируйте `WTF\Account\<аккаунт>\SavedVariables\Boses.lua` → `Bosses.lua` (плюс копию для персонажа), перезагрузите — заметки, настройки и журнал переедут сами
